## HW1 - Community Sports League Fixtures

A small web app for submitting football league fixtures (match title, venue,
submitter email, match details, status, and terms agreement). Built with plain
HTML, CSS, and JavaScript, then packaged with Docker and deployed to AWS ECS.

### Configuration

- SID4: 3319
- PORT_BASE: 8619
- PREFIX: s3319
- DOMAIN_ID: 7 (Community sports league fixtures)

### Files

- index.html - the fixture submission form
- style.css - page styling
- script.js - form validation and data handling
- Dockerfile - builds the container image
